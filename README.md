
## Atomic Blog App

![Create-react-app](https://github.com/AlinaAMG/React-Next.js-Redux/blob/atomic-blog/public/blog.png)

Atomic Blog App is een eenvoudige React-applicatie waarmee je blogs kunt beheren en weergeven. Deze app is gebouwd met Create React App en maakt gebruik van de faker-js package om dynamische voorbeelddata te genereren.

## Functionaliteiten

Blogs weergeven: Alle blogs worden dynamisch weergegeven in de UI met titel en inhoud.

Blogs beheren:

Nieuwe blogs toevoegen.

Blogs verbergen of weer zichtbaar maken.

De volledige lijst van blogs wissen.

Zoeken in blogs: Filter blogs op basis van een zoekterm en zie direct hoeveel blogs overeenkomen met je zoekopdracht.

UI updates: De UI wordt automatisch bijgewerkt bij wijzigingen in de lijst of bij zoeken.

Gebruik van React hooks:

useState voor state management van blogs en zoekterm.

useEffect voor het laden van initiële faker-data bij het opstarten van de app.

Mapping door posts: Dynamisch genereren van blogcomponenten door te mappen over de lijst van posts.

Weergave van blogdetails: Titel en body van elke blog worden netjes weergegeven.

## Gebruikte technologieën

React (via Create React App)

faker-js (@faker-js/faker) voor het genereren van voorbeeldblogs

JavaScript ES6+ (functional components, hooks)

CSS voor styling
