
# 🏦 The React-Redux Bank App ⚛️

Een eenvoudige bankapplicatie gebouwd met **React** en **Redux Toolkit**. Gebruikers kunnen zich registreren, geld storten/opnemen, leningen aanvragen en hun saldo beheren. Deze app is bedoeld om de basis van Redux Toolkit en React samen te brengen in een praktische context.

## 🔧 Features

- Klant aanmaken met naam en nationaal ID
- Stortingen en opnames beheren
- Leningen aanvragen en terugbetalen
- Valutaconversie simuleren (USD, EUR, GBP)
- Dynamische interface op basis van klantstatus
- Laden van asynchrone acties via `isLoading` state
- Statebeheer via Redux Toolkit `createSlice` en `configureStore`

## 🧱 Tech Stack

- React (met component state en JSX)
- Redux Toolkit (`createSlice`, `configureStore`)
- React-Redux (`useSelector`, `useDispatch`, `connect`)
- ESModules
- CSS (basisopmaak)
