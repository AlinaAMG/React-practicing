## Backroads App

Dit project is een vertaling van de bestaande HTML-versie van de Backroads-website naar React.
De focus ligt op het toepassen van de basisprincipes van React, namelijk components en props.

## Doel

Het doel van dit project is om te oefenen met:

  - Het opsplitsen van de website in herbruikbare React-componenten.

  - Het doorgeven van data via props.

  - Het opslaan van herbruikbare data in een apart bestand (data.js).

  - Het begrijpen van de fundamentele structuur van een React-app.

##  Gebruikte technologieën

React (functionele components)

Props voor dataoverdracht

CSS voor styling

Data bestand (data.js) voor herbruikbare content
